🌿 What is a Website Carbon Footprint?

Every time someone visits a website, data is transferred from servers to their device. This process consumes electricity, which often comes from fossil fuels, producing carbon dioxide (CO₂) emissions.

The carbon footprint of a website is the total CO₂ emissions generated per visit, measured in grams of CO₂ equivalent (gCO₂e).

🌍 Average website: ~1.76g CO₂ per visit

📊 Calculation Methodology

Our analyser estimates carbon footprint using a combination of factors:

  • 📦 Data Transfer — Size of all assets loaded
  • 📨 HTTP Requests — Number of server requests
  • 🖼️ Images — Number and size of images
  • 📜 Scripts — JavaScript and CSS files
  • 🔤 Fonts — Web fonts loaded
  • 🔗 Third-party — External resources (analytics, ads, etc.)

⚡ Emission Factors Used

Each factor is multiplied by a carbon intensity value based on global average grid electricity:

  • 📊 Data Transfer: 1.5 gCO₂/MB
  • 📨 HTTP Requests: 0.8 gCO₂/100 req
  • 🖼️ Images: 0.5 gCO₂/10 images
  • 📜 Scripts: 0.6 gCO₂/10 scripts
  • 🔤 Fonts: 0.3 gCO₂/10 fonts
  • 🔗 Third-party: 0.7 gCO₂/10 requests

Based on data from Website Carbon and Green Web Foundation.

🧮 The Formula

Total CO₂ =
(DataMB × 1.5) +
(Requests ÷ 100 × 0.8) +
(Images ÷ 10 × 0.5) +
(Scripts ÷ 10 × 0.6) +
(Fonts ÷ 10 × 0.3) +
(ThirdParty ÷ 10 × 0.7)

Each component is measured in grams of CO₂ per visit.

🌳 Tree Equivalence

To make the impact more tangible, we convert CO₂ emissions into tree equivalence — how many trees would be needed to absorb that CO₂ in a day.

1 Tree absorbs ~20kg CO₂ per year
= ~54.8g CO₂ per day
🌳 Trees needed = CO₂ (g) ÷ 54.8

🌎 Why This Matters

📊 The Numbers

  • 🌐 ~4.6 billion internet users worldwide
  • ⚡ Internet uses ~7% of global electricity
  • 💨 Digital carbon footprint = ~3.7% of global emissions
  • 📈 Growing ~6% per year

💚 What You Can Do

  • ✅ Optimise images and assets
  • ✅ Use green hosting
  • ✅ Reduce third-party scripts
  • ✅ Enable caching and compression
  • ✅ Choose sustainable web design
💡 Small changes add up! If every website reduced its footprint by 1g CO₂ per visit, we could save millions of tonnes of CO₂ annually.
